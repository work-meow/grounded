# Памятка по релизам

## Перед выкладкой
1. Прогнать тесты и линтеры во всех трёх проектах.
2. Проверить, что миграции описывают то же, что модели: `alembic check`.
3. Убедиться, что CI зелёный целиком, включая smoke.

## Выкладка
```
docker compose pull && docker compose up -d
```
Миграции применяются на старте контейнера — отдельного шага нет.

## После
- Проверить `/api/health` и состояние подключённых источников.
- Прогнать набор оценки: `docker compose exec backend python evals/run.py`.
- Раз в месяц чистить безымянные образы: `docker image prune -f`.
