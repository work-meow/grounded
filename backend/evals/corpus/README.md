# Корпус для оценки

Пять коротких документов, на которых написан `../questions.toml`. Загрузите их
в свежую установку — и числа из README будут сопоставимы с вашими.

```bash
for f in backend/evals/corpus/*.md; do
  curl -b cookies -F "file=@$f" https://ваш-адрес/api/sources
done
```

Содержимое выдуманное: договор, регламент, две внутренние памятки и онбординг.
Они подобраны так, чтобы вопросы к ним были проверяемыми (числа, сроки, имена
сторон), а не такими, где верный ответ — дело вкуса.
